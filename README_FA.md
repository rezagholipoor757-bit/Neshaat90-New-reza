# نشاط ۹۰ — نسخه اولیه قابل ساخت اندروید

این مخزن یک پروژه Android WebView با رابط فارسی است. ساخت APK در GitHub Actions تعریف شده است.

## ساخت APK ابری
1. این ZIP را در یک مخزن GitHub جدید با نام Neshaat90 بارگذاری کنید.
2. از زبانه Actions، گردش کار Build Neshaat90 APK را اجرا کنید.
3. پس از پایان موفق، از بخش Artifacts فایل `Neshaat90-debug-apk` را دریافت کنید.
4. فایل `app-debug.apk` را روی گوشی نصب کنید.

## وضعیت آزمایش
- منطق تولید سمت JavaScript است و از کلید یکتای ردیف‌ها برای جلوگیری از تکرار استفاده می‌کند.
- این محیط فاقد Android SDK، Gradle و دسترسی DNS برای دانلود ابزارهای ساخت است؛ بنابراین APK نهایی در این محیط ساخته یا نصب‌آزمایش نشده است.
- این نسخه پایه است؛ قبل از استفاده مالی واقعی باید پوشش احتمالات، مبالغ ۱۸ سطح و قواعد دقیق رادیکال با نمونه‌های مورد توافق تکمیل و آزمون شود.
